# Idea Brainstorming
* Neural network for galaxy morphology classification
* Bayesian hierarchical inference algorithm for fitting data
* Neural network for detection exoplanet transits

### Idea 1: Neural Network for Galaxy Morphology Classification
* Similar Implementation: https://arxiv.org/pdf/1807.10406
* Data set: https://data.galaxyzoo.org/
* **Intended User:** Astrophysicists, astronomers, student researchers etc. who need to classify large sets of galaxies. This project would assist with galaxy classification for large data surveys, such as SDSS, DESI, etc. and could contribute to astronomical research.
* **Problem/Need Rationale:** Modern astronomy and astrophysics research places large emphasis on the detection of new extragalactic objects, including galaxies of various morphologies, sizes, structures, etc. Classifying these galaxies based on morphology is usually done via crowdsourcing volunteers, experts, etc. These manual classifications are time consuming and inefficient. However, using machine learning has been an increasingly favorable approach in similar years to automate this process. As such, studying how neural networks can be applied to this astronomical task has tons of practical applications for this problem/neeed.
* **What the Program Would Allow the User to Do**: The program would allow the user to upload some sort of image file (probably a fits file) in monochrome. This file would then be transferred into a pixel array of floats denoting the pixel intensity, and then a neural network/machine learning algorithm would be trained to classify the image of the galaxy based on morphology. For now, I'm considering a simplified case in which either galaxy can be sorted into elliptical or spiral (two of the most common galaxy morphologies), and having a neural network classify images into these two bins. Further down the line, additional morphologies (S0/lenticular, dwarf/pseudobulge, etc.) could be incorporated and the neurla network could be trained to recognize these classifications as well.

### Idea 2: Bayesian hierarchical inference algorithm for fitting data
* Bayesian inference leverages Bayesian statistics and Markov Chain Monte Carlo (MCMC) to find the best fit parameters for any model given a data set. These sorts of fits are extremely useful in all areas of science, sociology, and data science, and as such this kind of project would have broad significance. A library containing the algorithm could be constructed, allowing other developers to access this and perform fits on data in their own scripts.
* **Intended User:** Data scientists, economists, quantitative finance researchers/traders, students, scientists (physicists, astronomers, biologists, chemists, etc.)
* **Problem/Need Rationale:** Bayesian fitting is highly relevant in the modern scene of computational research, and has broad applications. Existing implementations like PyMC, linmix, etc. are mostly limited to the Python environment. A Java implementation of a Bayesian algorithm and construction of a Java library could have benefits for researchers programming in Java.
* **What the Program Would Allow the User to Do:** The program (more likely some sort of library) would allow users to access external classes and methods in order to perform Bayesian fits of data. The user would programatically specify their model that they are fitting to in their script, pass in data arrays of x,y,z,and so on, and the program would leverage Bayes' theorem and Metropolis Monte Carlo (or Hamiltonian Monte Carlo) to fit and return the best model parameters.

### Idea 3: Neural network for exoplanet detection via transits
* Exoplanets are commonly detected in other star systems by looking for periodic dips in the flux (emitted light) of a star, indicating that an orbiting/transiting exoplanet is eclipsing and blocking part of the star. This method is known as exoplanet transit detection. Generally, deterministic algorithms are used to detect these transiting events given photometric data, however recently neural networks have been implemented with some success to automate detection and reduce computational expenses.
* **Intended User:** Astronomer, astrophysicist, student researcher trying to detect exoplanets. The project would have usefulness for large scale galactic surveys, gathered from telescopes, since it would be able to automatically process photometric data from these surveys and detect transit events.
* **Problem/Need Rationale:** Exoplanet detection relies on deterministic algorithms, which succeeding with varying degrees of accuracy and can be computationally expensive. Implementing a machine learning solution which leverages a trained neural network could improve this process of dettectrion, accuracy, and compute costs.
* **What the Program Would Allow the User to Do:** The program would probably be implemented as a library, and allow the user to call external methods/classes in their script which would launch the neural network to detect the transiting events. The user would likely pass in an array of measured fluxes and dates, and the neural network would determine whether a tranist ocurred, when, statistical significance, uncertainty, etc.
